# Tiny Source Notes ☕📝🐾

The public model stays synthetic and generic.

Some design questions were inspired by a long-running private coffee-routine history containing recurring **observable pattern classes** such as:

```text
+1 / explicit opt-in
pass
pause
resume
coffee delivered
reaction / acknowledgement
leave or exception updates
deferred payment / accounting shorthand
changing implementation details around a stable routine grammar
```

That history is **design inspiration**, not a public dataset and not evidence that the model has discovered anyone's hidden state.

```text
Private design history
        ↓ distill patterns, not private records
Generic design principle
        ↓
Synthetic teaching example
        ↓
Protocol / model-design question
```

The detailed public-safe distillation lives in [`design-principles.md`](design-principles.md).

It keeps three kinds of provenance separate:

```text
History-supported pattern class
→ recurring observable pattern motivated the question

Modeling interpretation
→ engineering abstraction created to represent or test the question

Epistemic guardrail
→ rule that prevents the model from claiming more than the evidence supports
```

Useful lessons include:

```text
A routine can be stable without becoming mandatory.
A pass can be valid without becoming failure.
Two sides can contribute differently without requiring 50/50 symmetry.
A disturbance can be temporary without becoming rupture.
Repeated coordination can accumulate context.
Implementation details can change while system semantics stay stable.
A missing clue is not automatically a zero-valued clue.
One anomaly is not automatically a new regime.
Historical probability does not commit the future.
```

The exact state ontology, equations, coefficients, Particle Filter, recovery metric, and other algorithms are **modeling choices**. The private source history did not hand us those answers.

No private messages, screenshots, private timestamps, company facts, raw exports, or private source files belong in this public repository.

The public Cheng / Linda personas are synthetic teaching characters, not a verbatim transcript and not a ground-truth psychology dataset.

```text
Design inspiration != public evidence
Public story != private data
Story != evidence
Model != human
```

Only distilled design patterns, generic semantics, and synthetic examples come out to play here. ☕🐣
