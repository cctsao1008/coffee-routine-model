# Tiny Transition Weather 🌦️🎲☕

## Why this exists

The fixed hybrid baseline uses:

```text
p(m_{t+1} | m_t)
```

Here `m_t` is the hidden routine mode at time `t`.

That remains the default for reproducibility.

The optional context-aware transition model asks a richer question:

```text
p(m_{t+1} | m_t, x_t, a_t, d_t, regime_t)
```

where `x_t` is hidden routine state, `a_t` is known action input, and `d_t` is explicit known context / disturbance.

The purpose is not to make mode changes deterministic. It is to let explicit, inspectable context nudge the stochastic transition probabilities when an experiment requires it.

This is a specialist lab connected to [`tutorial/07-weather-and-recovery.md`](tutorial/07-weather-and-recovery.md).

## Context features 🧺

The current hand-set prototype uses:

```text
friction
unpredictability
low mutuality
coordinated exception
recovery evidence
special-event signal
external disturbance
explicit regime logits
```

State-derived features come from the current particle state. Action-derived features come only from observable `RoutineActions`. External context such as a known special event or disturbance must be supplied explicitly.

```text
Context != telepathy
Context != deterministic mode choice
```

## How the dice move 🎲

For previous mode `i`, begin with the fixed transition row:

```text
base = P_fixed[m_t = i, :]
```

Then add bounded context nudges in log-probability space:

```text
logit_next
    = log(base)
    + feature_vector @ feature_effects
    + regime_logits
```

The total nudge for every target mode is clipped before softmax normalization.

One context event can change the distribution, but it cannot force:

```text
P(next mode = something) = 1
```

The dice remain stochastic.

## Semantic guardrails 🌱

- a voluntary `pass` alone does **not** secretly become Leave evidence;
- ordinary delivery + acknowledgment does **not** secretly become Recovery evidence;
- `Special` requires explicit special-event context rather than guessing from a callback;
- coordinated exception sync can make Leave more plausible without declaring failure;
- explicit closure / recovery hints can make Recovery more plausible;
- regime logits may bias target modes, but a change-point detector does not invent the direction of a regime change by itself.

## Fixed baseline stays available 🧺

`CoffeeParticleFilter` keeps fixed transitions by default.

Context-aware mode dynamics are opt-in:

```python
from coffee_brain.transitions import DEFAULT_CONTEXT_TRANSITIONS

pf = CoffeeParticleFilter(
    transition_config=DEFAULT_CONTEXT_TRANSITIONS,
)
```

Then an update may receive:

```python
pf.update(
    observation,
    actions=actions,
    transition_context=context,
)
```

This preserves the fixed reference baseline while allowing a separate context-aware experiment.

## Tiny weather race 🌦️🏁

Run:

```bash
python -m tiny_tools.compare_transitions \
  --days 400 \
  --seed 20260908
```

The benchmark generates an explicitly context-dependent synthetic mode sequence containing ordinary, disturbance, coordinated-exception, recovery, and special phases.

Both competitors see the same previous mode and synthetic sequence:

```text
context-aware transition model
vs
fixed transition matrix
```

It reports:

```text
negative log likelihood (NLL)
multiclass Brier score
top-1 mode accuracy
runtime-independent daily trace
```

and paints `transition-race.png`.

Because the synthetic truth is generated by the context model, this experiment checks whether the implementation can recover the advantage it was designed to have. It is **not** independent real-world validation.

## CI smoke-race reference 🐣🏁

The established continuous-integration (CI) smoke recipe uses `240` synthetic days with seed `20260908`:

```text
context-aware mean NLL : 1.0885
fixed-matrix mean NLL  : 1.1819
NLL improvement        : +0.0934

context-aware top-1    : 56.49%
fixed-matrix top-1     : 57.32%
```

This is useful because the metrics disagree in an informative way: the context-aware model assigns better probabilities to the sampled sequence, while the fixed matrix happens to win top-1 classification slightly on that run.

```text
Better probability model != guaranteed better argmax accuracy
One metric != model quality
```

The model arena extends the same principle across more competitors and keeps multiple trade-offs visible.

Tiny weather matters. Tiny dice stay stochastic. 🌦️🎲🐣
