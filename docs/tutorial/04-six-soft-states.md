# 04 — Six Modeling Questions Become Six Soft States 🌱🧠

The six CSRDM states should not feel like a list that appeared from nowhere.

Each one exists because a simpler description left out something useful.

## `P` — Predictability

Synthetic pattern:

```text
clear invite
→ clear opt-in / pass
→ expected handoff
→ ordinary continuation
```

Modeling question:

> Is the routine becoming easier to anticipate from repeated observable structure?

That motivates:

```text
P = Predictability
```

`P` is not “how predictable a person is.” It belongs to the routine model.

## `M` — Mutuality

Synthetic pattern:

```text
one side initiates more often
other side opts in, acknowledges, updates exceptions, or closes the loop
```

Modeling question:

> Can both sides help maintain the routine without contributing identical actions?

That motivates:

```text
M = Mutuality
```

```text
Mutuality != 50/50 symmetry
```

## `V` — Voluntariness

Synthetic pattern:

```text
+1?
pass
later: ordinary continuation
```

Modeling question:

> Can participation remain optional without the model interpreting every refusal as damage?

That motivates:

```text
V = Voluntariness
```

```text
Continuity != obligation
```

## `C` — Shared Context

Synthetic pattern:

```text
recurring shorthand
familiar coordination rules
remembered handoff conventions
callbacks that make sense because of earlier interactions
```

Modeling question:

> Should accumulated context survive longer than one daily observation?

That motivates:

```text
C = Shared Context
```

`C` later receives its own slow memory mechanism.

## `E` — Everyday State Sharing

Synthetic pattern:

```text
"busy today"
"on leave"
"back tomorrow"
```

when such information is explicitly shared as an observable update.

Modeling question:

> Should ordinary state/context information enter the model without pretending it reveals a hidden psychological truth?

That motivates:

```text
E = Everyday State Sharing
```

The model records that state information entered the interaction. It does not invent motives behind it.

## `F` — Friction

Synthetic pattern:

```text
more chasing
more ambiguity
harder coordination
more repair needed
```

Modeling question:

> Is keeping the routine coordinated becoming more costly or awkward?

That motivates:

```text
F = Friction
```

A low-friction routine is not automatically “better” in every human sense. It only means the coordination burden represented by this model is lower.

## Now the vector earns its notation

Only after the six questions are clear do we compress them into:

```text
x_t = [P, M, V, C, E, F]
```

Read `x_t` as the hidden routine-state vector at time `t`.

These are **latent properties of the routine model**.

They are not six ground-truth meters attached to either persona.

```text
Latent state != observed fact
Model variable != human essence
```

## Why one combined score is not enough

It would be easy to collapse everything into one “routine score.”

That would hide useful trade-offs:

```text
high continuity + low voluntariness
high predictability + high friction
strong accumulated context + temporary leave
```

Different state combinations can tell different model stories, so CSRDM keeps the dimensions visible.
